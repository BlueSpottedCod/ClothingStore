# Система управления магазином одежды

Это настольное приложение на Python с использованием `customtkinter` и SQLite. Программа предназначена для управления товарами, продажами и сотрудниками магазина, а также позволяет экспортировать отчёты о продажах в формате Excel.

---

## Минимальные требования

- Python 3.10 или выше  
- Библиотеки:
  - `customtkinter`
  - `openpyxl`
- Встроенные модули: `sqlite3`, `tkinter`

---

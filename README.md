# Система управления магазином одежды

Десктопное приложение на Python с использованием `customtkinter` и SQLite. Программа позволяет управлять товарами, продажами и сотрудниками магазина, а также экспортировать отчёты о продажах в формате Excel.

---

## Минимальные требования

- Python 3.10 или выше  
- Библиотеки:
  - `customtkinter`
  - `openpyxl`
- Встроенные модули: `sqlite3`, `tkinter`

---

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <URL_репозитория>
cd <имя_папки>

2. Создайте виртуальное окружение:

**Windows:**

```bash
python -m venv venv
```

**Linux/macOS:**

```bash
python3 -m venv venv
```

3. Активируйте виртуальное окружение:

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

4. Установите необходимые библиотеки:

```bash
pip install customtkinter openpyxl
```

5. Запустите приложение:

```bash
python app.py
```

6. Авторизация в приложении:

- **Логин:** `admin`  
- **Пароль:** `123456`

---

## Основные возможности

### Управление товарами
- Добавление и редактирование продукции  
- Удаление товаров из базы  
- Просмотр актуального списка продукции

### Продажи
- Регистрация новых продаж с автоматическим списанием товаров  
- Отчёты о продажах с отображением суммы и даты  
- Экспорт данных в Excel для анализа  
- Очистка всех продаж

### Работа с сотрудниками
- Добавление новых сотрудников  
- Редактирование данных персонала  
- Удаление сотрудников  
- Просмотр полного списка сотрудников

---

## Настройка и модификация

- Начальные данные (товары и сотрудники) задаются в функции `create_tables()`.  
- Excel-отчёты сохраняются в файл `sales_report.xlsx` в корне проекта.  
- Для расширения функционала можно модифицировать SQL-запросы или добавить новые окна и кнопки.

---

## Советы по использованию

- Перед добавлением продажи убедитесь, что на складе достаточно товара.  
- Для корректного экспорта в Excel закройте файл `sales_report.xlsx` перед повторным сохранением.  
- Все изменения данных сохраняются автоматически в базе SQLite.
